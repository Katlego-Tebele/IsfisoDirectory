## 🎯 3 Steps to Launch

### Step 1: Add Your Photos (15 minutes)

**Option A: Use the Automatic Generator**
1. Open `create-placeholder-images.html` in your browser
2. Click "Generate All Placeholder Images"
3. Move downloaded images to correct folders (instructions provided)

**Option B: Use Your Real Photos (Recommended)**
1. Read `IMAGE-GUIDE.md` for detailed instructions
2. Take photos of your completed projects
3. Rename files correctly (kitchen.jpg, wardrobe.jpg, etc.)
4. Place in `assets/images/services/` and `assets/images/gallery/`

### Step 2: Test Locally (2 minutes)

1. Double-click `index.html` to open in browser
2. Scroll through entire website
3. Click a WhatsApp button to test
4. Resize browser to test mobile view

### Step 3: Deploy Online (5-10 minutes)

**Easiest Method - Netlify (FREE):**
1. Go to https://www.netlify.com
2. Sign up (free)
3. Drag your entire project folder
4. Done! Your website is live

See `README.md` for other deployment options (GitHub Pages, InfinityFree, etc.)

## 🎨 Customization Basics

- `Isifiso-Sakho Carpentry` → Your business name
- `076 720 6347` → Your phone number
- `5181 Phumzile Street` → Your address

### Change Colors

**Open `assets/css/styles.css` and look for `:root` section:**

```css
:root {
    --color-primary: #8B4513;        /* Main brown color */
    --color-secondary: #D4A574;      /* Gold/beige accent */
    --color-cream: #FAF6F1;          /* Background cream */
}
```

Change these hex codes to your preferred colors.

### Add More Gallery Images

2. Name them: `project-7.jpg`, `project-8.jpg`, etc.
3. Open `index.html`

## 🆘 Common Questions

### Q: The website shows blank/broken images
**A:** This is normal! Add your photos following `IMAGE-GUIDE.md` or use `create-placeholder-images.html` to generate temporary ones.

### Q: WhatsApp button doesn't work
**A:** Make sure WhatsApp is installed. On desktop, you need WhatsApp Web. Test on your phone first.

### Q: How do I edit text?
**A:** Open `index.html` in any text editor (Notepad, Notepad++, VS Code) and search for the text you want to change.

### Q: How much does hosting cost?
**A:** FREE! Use Netlify, GitHub Pages, or InfinityFree. See `README.md` for instructions.

### Q: Can I add more services?
**A:** Yes! Copy an existing service card in `index.html` and modify the text. Don't forget to add a matching photo.

### Q: My changes don't show
**A:** Clear your browser cache (Ctrl+F5 on Windows, Cmd+Shift+R on Mac) or try in incognito mode.
