## 📱 Image Optimization Tips

### Before Uploading:

1. **Resize Images:**
   - Service images: 800-1000px width
   - Gallery images: 1200-1500px width
   - Hero background: 1920px width
   
2. **Compress Images:**
   - Use online tools:
     - https://tinypng.com (recommended)
     - https://squoosh.app
     - https://compressor.io
   - Aim for file sizes under 500KB each
   
3. **File Format:**
   - Use **JPG** for photos (best compression)
   - Use **PNG** only if you need transparency
   - **DO NOT** use BMP, TIFF, or RAW formats

4. **File Names:**
   - Use exact names listed above
   - All lowercase
   - No spaces (use hyphens)
   - Examples: ✅ `kitchen.jpg` ❌ `Kitchen Photo.JPG`

## 🎨 Photography Tips for Best Results

### Lighting:
- ✅ Natural daylight is best
- ✅ Open curtains, turn on all lights
- ❌ Avoid harsh shadows
- ❌ Avoid dark, dim photos

### Composition:
- ✅ Clean, tidy space before photographing
- ✅ Shoot from eye level or slightly above
- ✅ Include context (show the whole room)
- ✅ Multiple angles of same project
- ❌ Don't crop out important details
- ❌ Avoid cluttered backgrounds

### Quality:
- ✅ Hold phone/camera steady
- ✅ Make sure image is in focus
- ✅ Take multiple shots, pick the best
- ❌ Avoid blurry or pixelated images
- ❌ Don't use flash (creates harsh shadows)

## ❓ FAQ

**Q: Can I use different file names?**
A: Yes, but you'll need to update the file paths in `index.html`. It's easier to use the suggested names.

**Q: My images are too large (several MB each)**
A: Compress them using TinyPNG before uploading. Large images slow down your website.

**Q: Can I add more than 6 gallery images?**
A: Absolutely! Just name them project-7.jpg, project-8.jpg, etc. and add them to the HTML.

**Q: What if I don't have photos for a service yet?**
A: Use a temporary stock photo until you have real photos. Replace as soon as possible.

**Q: Should images be horizontal or vertical?**
A: Service images work best as horizontal (landscape). Gallery images can be either.

**Q: The website works but images don't show**
A: Check that:
1. File names match exactly (case-sensitive)
2. Files are in correct folders
3. Files are .jpg or .png format
4. You've refreshed the browser

## 📞 Need Help?

If you're having trouble with images:

1. **Check file locations** - Make sure files are in the right folders

3. **Check file format** - Must be .jpg or .png
4. **Try clearing browser cache** - Press Ctrl+F5
