## ⚠️ Important Notes:

### About floor.webp:
The floor image is in .webp format. The website expects .jpg. You have 2 options:

**Option A (Quick):** Just rename it to `flooring.webp` and update the HTML
**Option B (Better):** Convert it to JPG first:
- Open floor.webp in Paint
- Save As → JPEG → name it "flooring.jpg"
- Copy to services folder

### About .jpeg vs .jpg:
Both work in websites, but for consistency, rename .jpeg files to .jpg by:
- Right-click file → Rename
- Change the extension from .jpeg to .jpg
